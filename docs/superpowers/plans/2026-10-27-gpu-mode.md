# GPU mode (`-gpu`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Blink executable accepts `-gpu`; the Benchmarks that have Data buffers then run the same MPI calls on GPU memory (GPU-aware MPI), with CUDA and HIP support.

**Architecture:** A vendor-only wrapper (`src/gpu.c`, plain C, no MPI-specific logic) provides alloc/free/copy/memset. `src/gpu_mode.c` adds the `-gpu` runtime (device mapping, GPU-aware-MPI probe, and the `data_*` mirror calls). A Benchmark keeps its host buffers and host fill/verify loops unchanged and hands MPI device *mirrors* of them (`data_mirror`); in Host mode a mirror is the host pointer itself, so the host path is byte-identical. No GPU kernels exist, so everything compiles with plain gcc.

**Tech Stack:** C99 / C++ (existing), CMake >= 3.16 (presets need >= 3.21), Open MPI + CUDA 13.4 on this machine (HIP: no hardware or ROCm here), GTest (existing).

**Spec:** `CONTEXT.md` (glossary), `docs/adr/0001-gpu-aware-mpi-only.md` (decision), `docs/gpu-open-questions.md` (assumptions to validate with the professor, incl. the RMA finding). The design was settled in a grilling session; the decisions are restated under Global Constraints.

## Global Constraints

- Flag is `-gpu` (single dash, like every existing flag). No `--gpu`. Parsed once, in `parse_common_args` (`src/common.c`).
- Host mode must stay byte-identical: same stdout, same MPI calls, same timing code. Only Data-buffer *pointers handed to MPI* change.
- The timed region is never touched. All GPU work (mirror upload, probe, fetch, free) happens outside it.
- `-gpu` messages (warnings, probe notes, errors) go to **stderr**, once, from rank 0. Stdout carries only what it carries today plus the per-rank `DEBUG rank=R gpu=1 device=D` line under `-debug`.
- `durations`, request arrays, tags arrays and the results gather stay on the host (`malloc_align`).
- No GPU kernels and no `.cu` files. Only `src/gpu.c` may include `cuda_runtime_api.h` / `hip/hip_runtime_api.h`.
- Device for a rank = `node_local_rank % visible_device_count`, set after `MPI_Init`, after the flags are parsed.
- `-gpu` on a Buffer-less executable: accepted, runs exactly as before, one stderr warning, exit code 0.
- `-gpu` on a binary built without GPU support (and with Data buffers): exit non-zero with `built without GPU support`.
- `BLINK_GPU` CMake cache variable: `AUTO` (default) | `OFF` | `CUDA` | `HIP`. Explicit `CUDA`/`HIP` fail configure if the toolkit is missing.
- Every task ends committed on branch `gpu`. Nothing is pushed or merged without the user's explicit go-ahead.
- Commit trailer (from the session's attribution reminder): `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

- `$SCRATCH` below means the session scratchpad directory (`/tmp/claude-1000/-home-marcio-Documents-Uni-Lavoro-blink/68a91094-1417-4ff0-9d4e-53e9f4c93bb6/scratchpad`).
- Host-mode check done at planning time: `alltoall_b -msgsize 0` already exits 0, and every benchmark sets `my_rank`/`w_size` before `parse_common_args` (the probe in it relies on that).

## Review Focus

Inputs the design implies but the happy-path tests do not exercise, most likely to bite first:

1. `-msgsize 0 -gpu`: the device allocation must not fail (`gpu_malloc(0)` allocates 1 byte); exit 0 (Task 5 test).
2. One-sided on device memory (`incast_get`, `incast_put`): on this machine the data silently does not arrive. `-gpu` must abort with the "... not supported by this MPI" message, never report timings or exit 0 with `check=FAIL` (Task 4 probe, Task 10 test).
3. `-gpu` on a build without GPU support: clear non-zero exit, not a segfault (Task 4 test).
4. `-gpu` on a Buffer-less executable (`barrier_b`, `null_dummy`): exit 0, stdout unchanged, one warning (Task 4 test).
5. More local ranks than GPUs and/or a large `-msgsize`: device allocation failure must abort with the CUDA/HIP error text, not hang (covered by `gpu_fail` in Task 2, unit test of the failure path is not possible without exhausting memory; documented in README, Task 11).

```c
/* Vendor wrapper: the only file in Blink that includes CUDA / HIP headers.
 * BLINK_GPU_CUDA or BLINK_GPU_HIP is defined by CMake for GPU builds; with
 * neither defined every call except gpu_available/gpu_backend_name/
 * gpu_device_count is fatal ("built without GPU support").                   */
#include <stdio.h>
#include <stdlib.h>
#include <mpi.h>
#include "gpu.h"

#if defined(BLINK_GPU_CUDA)
#  include <cuda_runtime_api.h>
#  define GPU_BACKEND_NAME      "CUDA"
#  define gpuError_t            cudaError_t
#  define gpuSuccess            cudaSuccess
#  define gpuGetErrorString     cudaGetErrorString
#  define gpuGetDeviceCount     cudaGetDeviceCount
#  define gpuSetDevice          cudaSetDevice
#  define gpuMalloc             cudaMalloc
#  define gpuFree               cudaFree
#  define gpuMemset             cudaMemset
#  define gpuMemcpy             cudaMemcpy
#  define gpuMemcpyHostToDevice cudaMemcpyHostToDevice
#  define gpuMemcpyDeviceToHost cudaMemcpyDeviceToHost
#  define gpuMemcpyDeviceToDevice cudaMemcpyDeviceToDevice
#  define gpuDeviceSynchronize  cudaDeviceSynchronize
#elif defined(BLINK_GPU_HIP)
#  include <hip/hip_runtime_api.h>
#  define GPU_BACKEND_NAME      "HIP"
#  define gpuError_t            hipError_t
#  define gpuSuccess            hipSuccess
#  define gpuGetErrorString     hipGetErrorString
#  define gpuGetDeviceCount     hipGetDeviceCount
#  define gpuSetDevice          hipSetDevice
#  define gpuMalloc             hipMalloc
#  define gpuFree               hipFree
#  define gpuMemset             hipMemset
#  define gpuMemcpy             hipMemcpy
#  define gpuMemcpyHostToDevice hipMemcpyHostToDevice
#  define gpuMemcpyDeviceToHost hipMemcpyDeviceToHost
#  define gpuMemcpyDeviceToDevice hipMemcpyDeviceToDevice
#  define gpuDeviceSynchronize  hipDeviceSynchronize
#endif

static void gpu_fail(const char *what, const char *why)
{
    fprintf(stderr, "GPU error in %s: %s\n", what, why);
    int init = 0;
    MPI_Initialized(&init);
    if (init) MPI_Abort(MPI_COMM_WORLD, -1);
    exit(1);
}

#ifdef GPU_BACKEND_NAME

#define GPU_CHECK(call) do {                                   \
        gpuError_t e_ = (call);                                \
        if (e_ != gpuSuccess) gpu_fail(#call, gpuGetErrorString(e_)); \
    } while (0)

int         gpu_available(void)    { return 1; }
const char *gpu_backend_name(void) { return GPU_BACKEND_NAME; }

int gpu_device_count(void)
{
    int n = 0;
    if (gpuGetDeviceCount(&n) != gpuSuccess) return 0;
    return n;
}

void gpu_set_device(int dev) { GPU_CHECK(gpuSetDevice(dev)); }

void *gpu_malloc(size_t n)
{
    void *p = NULL;
    GPU_CHECK(gpuMalloc(&p, n ? n : 1));
    return p;
}

void gpu_free(void *p)                                { GPU_CHECK(gpuFree(p)); }
void gpu_memset(void *dst, int value, size_t n)       { GPU_CHECK(gpuMemset(dst, value, n)); GPU_CHECK(gpuDeviceSynchronize()); }
/* sync after h2d: a pageable-memory cudaMemcpy may return before the DMA finished, and a peer
 * (CUDA IPC / UCX copy stream) could then read stale bytes.  All h2d copies are outside timed regions. */
void gpu_memcpy_h2d(void *dst, const void *src, size_t n) { GPU_CHECK(gpuMemcpy(dst, src, n, gpuMemcpyHostToDevice)); GPU_CHECK(gpuDeviceSynchronize()); }
void gpu_memcpy_d2h(void *dst, const void *src, size_t n) { GPU_CHECK(gpuMemcpy(dst, src, n, gpuMemcpyDeviceToHost)); }
void gpu_memcpy_d2d(void *dst, const void *src, size_t n) { GPU_CHECK(gpuMemcpy(dst, src, n, gpuMemcpyDeviceToDevice)); GPU_CHECK(gpuDeviceSynchronize()); }
void gpu_sync(void)                                   { GPU_CHECK(gpuDeviceSynchronize()); }

#else  /* no backend compiled in */

#define NO_GPU() gpu_fail(__func__, "built without GPU support; reconfigure with -DBLINK_GPU=CUDA or -DBLINK_GPU=HIP")

int         gpu_available(void)    { return 0; }
const char *gpu_backend_name(void) { return "none"; }
int         gpu_device_count(void) { return 0; }
void        gpu_set_device(int dev) { (void)dev; NO_GPU(); }
void       *gpu_malloc(size_t n)    { (void)n; NO_GPU(); return NULL; }
void        gpu_free(void *p)      { (void)p; NO_GPU(); }
void        gpu_memset(void *d, int v, size_t n)               { (void)d; (void)v; (void)n; NO_GPU(); }
void        gpu_memcpy_h2d(void *d, const void *s, size_t n)   { (void)d; (void)s; (void)n; NO_GPU(); }
void        gpu_memcpy_d2h(void *d, const void *s, size_t n)   { (void)d; (void)s; (void)n; NO_GPU(); }
void        gpu_memcpy_d2d(void *d, const void *s, size_t n)   { (void)d; (void)s; (void)n; NO_GPU(); }
void        gpu_sync(void)         { NO_GPU(); }

#endif
```

```cmake
# GPU backend selection.  AUTO probes CUDA, then HIP, then falls back to a
# host-only build.  Only the C runtime libraries are linked: no kernels exist,
# so neither nvcc nor hipcc is needed.
set(BLINK_GPU "AUTO" CACHE STRING "GPU backend: AUTO, OFF, CUDA or HIP")
set_property(CACHE BLINK_GPU PROPERTY STRINGS AUTO OFF CUDA HIP)
string(TOUPPER "${BLINK_GPU}" _blink_gpu_req)
if(NOT _blink_gpu_req MATCHES "^(AUTO|OFF|CUDA|HIP)$")
    message(FATAL_ERROR "BLINK_GPU must be AUTO, OFF, CUDA or HIP (got '${BLINK_GPU}')")
endif()
set(BLINK_GPU_BACKEND "NONE")
if(_blink_gpu_req STREQUAL "CUDA" OR _blink_gpu_req STREQUAL "AUTO")
    find_package(CUDAToolkit QUIET)
    if(CUDAToolkit_FOUND)
        set(BLINK_GPU_BACKEND "CUDA")
    elseif(_blink_gpu_req STREQUAL "CUDA")
        message(FATAL_ERROR "BLINK_GPU=CUDA but no CUDA toolkit was found (set CUDAToolkit_ROOT)")
    endif()
endif()
if(BLINK_GPU_BACKEND STREQUAL "NONE" AND (_blink_gpu_req STREQUAL "HIP" OR _blink_gpu_req STREQUAL "AUTO"))
    find_package(hip QUIET HINTS /opt/rocm $ENV{ROCM_PATH})
    if(hip_FOUND)
        set(BLINK_GPU_BACKEND "HIP")
    elseif(_blink_gpu_req STREQUAL "HIP")
        message(FATAL_ERROR "BLINK_GPU=HIP but no ROCm/HIP was found (set CMAKE_PREFIX_PATH=/opt/rocm)")
    endif()
endif()
message(STATUS "BLINK_GPU: requested ${BLINK_GPU}, using ${BLINK_GPU_BACKEND}")
```

function(add_benchmark_test name nprocs)
    add_executable(${name} ${name}.cpp)
    target_include_directories(${name} PRIVATE ${CMAKE_CURRENT_SOURCE_DIR})
    if(BLINK_GPU_BACKEND STREQUAL "NONE")
        set(_gpu_build 0)

        "BLINK_BIN_DIR=\"${CMAKE_BINARY_DIR}/bin\""
        "BLINK_MPIEXEC=\"${MPIEXEC_EXECUTABLE}\""

```c
#include "common.h"
#include "gpu.h"

#if defined(OPEN_MPI) && OPEN_MPI
#  include <mpi-ext.h>   /* MPIX_CUDA_AWARE_SUPPORT / MPIX_ROCM_AWARE_SUPPORT */
#endif

/* "yes" | "no" | "unknown ..." according to the MPI's own query, when it has one. */
static const char *mpi_reports_gpu_support(void)
{
#if defined(MPIX_CUDA_AWARE_SUPPORT)
    if (strcmp(gpu_backend_name(), "CUDA") == 0) {
#  if MPIX_CUDA_AWARE_SUPPORT
        return MPIX_Query_cuda_support() ? "yes" : "no";
#  else
        return "no (MPI built without CUDA support)";
#  endif
    }
#endif
#if defined(MPIX_ROCM_AWARE_SUPPORT)
    if (strcmp(gpu_backend_name(), "HIP") == 0) {
#  if MPIX_ROCM_AWARE_SUPPORT
        return MPIX_Query_rocm_support() ? "yes" : "no";
#  else
        return "no (MPI built without ROCm support)";
#  endif
    }
#endif
    return "unknown (not queryable with this MPI)";
}

/* Untimed collective check that the MPI moves data from/to device memory:
 * a ring MPI_Sendrecv and an MPI_Allreduce(SUM) over ints.  Returns 1 on all ranks if correct. */
static int probe_pt2pt(void)
{
    enum { N = 16 };
    int h[N], r[N], i, ok = 1, all = 0;
    int *ds = (int *)gpu_malloc(N * sizeof(int));
    int *dr = (int *)gpu_malloc(N * sizeof(int));
    int to = (my_rank + 1) % w_size, from = (my_rank + w_size - 1) % w_size;

    for (i = 0; i < N; i++) h[i] = my_rank + 1;
    gpu_memcpy_h2d(ds, h, sizeof h);
    gpu_memset(dr, 0, sizeof h);
    MPI_Sendrecv(ds, N, MPI_INT, to, 7, dr, N, MPI_INT, from, 7, MPI_COMM_WORLD, MPI_STATUS_IGNORE);
    gpu_memcpy_d2h(r, dr, sizeof r);
    for (i = 0; i < N; i++) if (r[i] != from + 1) ok = 0;

    gpu_memset(dr, 0, sizeof h);
    MPI_Allreduce(ds, dr, N, MPI_INT, MPI_SUM, MPI_COMM_WORLD);
    gpu_memcpy_d2h(r, dr, sizeof r);
    for (i = 0; i < N; i++) if (r[i] != w_size * (w_size + 1) / 2) ok = 0;

    gpu_free(ds); gpu_free(dr);
    MPI_Allreduce(&ok, &all, 1, MPI_INT, MPI_MIN, MPI_COMM_WORLD);
    return all;
}

/* One-sided probe (only for benchmarks that use MPI_Win): Put then Get on a window over
 * device memory.  Some MPIs accept this and silently transfer nothing. */
static int probe_rma(void)
{
    enum { N = 16 };
    int h[N], r[N], i, ok = 1, all = 0;
    int *ds = (int *)gpu_malloc(N * sizeof(int));
    int *dw = (int *)gpu_malloc(N * sizeof(int));
    int *dg = (int *)gpu_malloc(N * sizeof(int));
    int to = (my_rank + 1) % w_size, from = (my_rank + w_size - 1) % w_size;
    MPI_Win win;

    for (i = 0; i < N; i++) h[i] = my_rank + 1;
    gpu_memcpy_h2d(ds, h, sizeof h);
    gpu_memset(dw, 0, sizeof h);
    gpu_memset(dg, 0, sizeof h);
    MPI_Win_create(dw, N * sizeof(int), sizeof(int), MPI_INFO_NULL, MPI_COMM_WORLD, &win);
    MPI_Win_fence(0, win);
    MPI_Put(ds, N, MPI_INT, to, 0, N, MPI_INT, win);
    MPI_Win_fence(0, win);
    gpu_memcpy_d2h(r, dw, sizeof r);
    for (i = 0; i < N; i++) if (r[i] != from + 1) ok = 0;
    MPI_Win_fence(0, win);
    MPI_Get(dg, N, MPI_INT, to, 0, N, MPI_INT, win);   /* window of `to` holds my_rank+1 */
    MPI_Win_fence(0, win);
    gpu_memcpy_d2h(r, dg, sizeof r);
    for (i = 0; i < N; i++) if (r[i] != my_rank + 1) ok = 0;
    MPI_Win_free(&win);

    gpu_free(ds); gpu_free(dw); gpu_free(dg);
    MPI_Allreduce(&ok, &all, 1, MPI_INT, MPI_MIN, MPI_COMM_WORLD);
    return all;
}

void gpu_setup(void)
{
    if (!use_gpu) return;

    if (!benchmark_has_data_buffers) {
        if (my_rank == 0)
            fprintf(stderr, "warning: -gpu has no effect: this executable has no data buffers\n");
        use_gpu = 0;
        return;
    }
    if (!gpu_available()) {
        if (my_rank == 0)
            fprintf(stderr, "-gpu: built without GPU support; reconfigure with -DBLINK_GPU=CUDA or -DBLINK_GPU=HIP\n");
        MPI_Abort(MPI_COMM_WORLD, -1);
    }

    /* node-local rank -> device */
    MPI_Comm local;
    int lrank, lsize, ndev, over, any_over, dev;
    MPI_Comm_split_type(MPI_COMM_WORLD, MPI_COMM_TYPE_SHARED, my_rank, MPI_INFO_NULL, &local);
    MPI_Comm_rank(local, &lrank);
    MPI_Comm_size(local, &lsize);
    MPI_Comm_free(&local);
    ndev = gpu_device_count();
    if (ndev <= 0) {
        fprintf(stderr, "rank %d: -gpu: no %s device visible\n", my_rank, gpu_backend_name());
        MPI_Abort(MPI_COMM_WORLD, -1);
    }
    dev = lrank % ndev;
    gpu_set_device(dev);

    over = (lsize > ndev);
    MPI_Allreduce(&over, &any_over, 1, MPI_INT, MPI_MAX, MPI_COMM_WORLD);
    if (my_rank == 0) {
        fprintf(stderr, "GPU mode: backend %s, %d device(s) visible on node of rank 0; "
                        "MPI reports GPU support: %s; probing GPU-aware MPI...\n",
                gpu_backend_name(), ndev, mpi_reports_gpu_support());
        if (any_over)
            fprintf(stderr, "warning: more ranks than GPUs on some node; ranks share devices (device = local_rank %% #devices)\n");
    }

    if (!probe_pt2pt()) {
        if (my_rank == 0)
            fprintf(stderr, "GPU-aware MPI probe FAILED: device-memory Sendrecv/Allreduce returned wrong data\n");
        MPI_Abort(MPI_COMM_WORLD, -1);
    }
    if (benchmark_uses_rma) {
        if (my_rank == 0)
            fprintf(stderr, "probing one-sided communication on device memory...\n");
        if (!probe_rma()) {
            if (my_rank == 0)
                fprintf(stderr, "one-sided (MPI_Win/Put/Get) on GPU memory is not supported by this MPI: data was not transferred\n");
            MPI_Abort(MPI_COMM_WORLD, -1);
        }
    }

    if (debug_mode) {
        printf("DEBUG rank=%d gpu=1 device=%d\n", my_rank, dev);
        fflush(stdout);
    }
}

void *data_mirror(void *host, size_t n)
{
    if (!use_gpu) return host;
    void *dev = gpu_malloc(n);
    gpu_memcpy_h2d(dev, host, n);
    return dev;
}
void data_push(void *mirror, const void *host, size_t n)  { if (use_gpu) gpu_memcpy_h2d(mirror, host, n); }
void data_fetch(void *host, const void *mirror, size_t n) { if (use_gpu) gpu_memcpy_d2h(host, mirror, n); }
void data_free(void *mirror)                              { if (use_gpu) gpu_free(mirror); }
void data_copy(void *dst, const void *src, size_t n)
{
    if (use_gpu) gpu_memcpy_d2d(dst, src, n);
    else         memcpy(dst, src, n);
}
```
Note: when the host buffer is `n == 0` bytes, `data_mirror` still returns a valid 1-byte device pointer (wrapper guarantee), so `data_free` is always valid.
